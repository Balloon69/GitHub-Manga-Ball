# Ep.5 Parallel War

น้องจิ้งจอกเดินทางข้าม “เส้นเวลา” ผ่านพลังแห่งโลกคู่ขนาน
เขาปรากฏตัวในจักรวาลแรก — โลกที่บอสยังมีชีวิต
แต่ที่นั่น เขากลับพบว่า “ตัวเขาเอง” ในโลกนี้ เป็นหนึ่งในผู้นำของแก๊งที่ฆ่าบอสในโลกเดิม

“ฉันทำร้ายบอส...ในจักรวาลอื่นน่ะเหรอ?”
“หรือฉัน... คือภัยคุกคามในทุกจักรวาลกันแน่?”

เขาเริ่มสงสัยในตัวเองมากขึ้น แต่ไม่มีเวลาพอจะลังเล
เพราะ “เงาแห่งตัวเขาเอง” จากอีกหลายจักรวาล เริ่มไล่ล่าเขา —
บางคนต้องการปกป้องจักรวาลของตน บางคนต้องการพลังแบบเขา

เขาต้องตัดสินใจ:
จะเป็น “ผู้กอบกู้” หรือ “ผู้ล้างโลก”
